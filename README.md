# world-sim

从物理定律一层层往上，一直模拟到文明。

这个仓库里是一组各自独立的模拟项目。每个项目起于一段很短的想法，挂在同一条尺度阶梯的某一层上；合起来是在回答同一个问题：下一层的一群，怎么变成上一层的一个。

## 阶梯与项目

| 层 | 基元 | 这一层新出现的东西 | 项目 |
|---|---|---|---|
| L1 物质 | 粒子 | 温度、压强、相变 | [`strata/`](strata) — 从微观规则到涌现 |
| L2 分子与细胞 | 分子 | 结构、催化、拥挤中的秩序 | [`limn/`](limn) — Goodsell 风格的科学插图 |
| L3 组织与器官 | 细胞 | 形态、节律、防御 | — |
| L4 身体 | 器官 | 一个活着的整体、疼痛 | [`soma/`](soma) — 三维人体解剖 |
| L5 一个人 | 念头、习惯 | 自我、欲望、选择 | — |
| L6 两个人 | 人 | 互猜、信任、讨价还价 | [`mindloop/`](mindloop) — 我知道你知道我知道 |
| L7 一小群人 | 人 | 结盟、秘密、教与学 | — |
| L8 社会 | 人群 | 市场、谣言、货币、城市 | [`polis/`](polis) — 平行社会 |
| L9 文明 | 社会 | 语言、制度、观念的寿命 | — |
| L10 生命与行星 | 物种、圈层 | 演替、协同演化、气候 | — |

每个项目目录自成一体，有自己的技术栈、测试和说明。项目由各自的会话通过 PR 加入，目录还不存在说明它尚未提交。

## 想法池

[`IDEAS.md`](IDEAS.md) 里是：

- 已有项目的共性与差异
- 一个模拟的通用结构
- 一条主干（上面的阶梯）和五条横线（传播、临界与崩溃、互猜的深度、记忆、层与层的接口）
- 几条纵线（同一件事穿过所有层）和两条支线（人造的东西、纯粹的规则世界）
- 按计算内核的聚类：哪些 idea 共用同一种底层计算
- 按层排列的 idea，每一条都是可以直接交给 Claude 开工的一段输入
- 覆盖情况：阶梯上每一格有几条，哪里还薄
- 一个构想：这些模拟以后怎么在结构、引擎和界面上连起来（现在不执行，先各做各的）

## 共同的做法

这些不是规定，是几个项目各自做出来之后发现相同的地方：

- **契约先行**：先写数据契约，引擎写、界面读。
- **内容与机制分离**：案例、场景、数据是一回事，规则是另一回事。
- **数值来自确定性内核**：同样的参数和种子必须得到同样的结果；语言模型只做旁白。
- **有现实锚点**：每个模拟都要能复现现实里的某样东西——守恒律、测量数据、一个有出处的故事的结局。
- **测不变量**：测试针对内核，检查的是规律而不是快照。

## 提交方式

所有改动都走 PR，`main` 不接受直接推送。仓库所有者从本仓库分支发起的 PR 会被自动 squash 合并。

```sh
tools/pr.sh "<标题>" <路径>...

# 例
tools/pr.sh "strata: 加入三维盒子" strata
COMMIT_BODY="补上 L3 和 L7 的空缺" tools/pr.sh "ideas: 第 5 批" IDEAS.md
```

脚本只提交列出的路径，不切分支，也不动工作目录里别的项目，所以多个会话可以同时在同一个目录里工作。细节见 [`CLAUDE.md`](CLAUDE.md)。
