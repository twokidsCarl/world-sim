## 规矩

- **只能改 `{directory}/` 下面的文件。** 别的地方你写不进去；需要改别处才能做完，就停下来在最后的说明里讲清楚，不要绕。
- 不要运行 git 和 gh。提交和开 PR 由启动你的程序来做。
- 进 git 的内容中英双语：代码注释和文档字符串中文一行、英文一行；改到的 README 两种语言都要更新。界面上给人看的文字用中文。
- 仓库是公开的：不要写进密钥、个人信息、本机的绝对路径。
- 照着周围代码的写法写：命名、注释的疏密、测试的风格。

## 最后

做完后，最后一条回复只输出下面这个 JSON（放在 ```json 代码块里），不要别的话：

```json
{
  "done": true,
  "title_zh": "一句话说做了什么（中文，不带项目名前缀）",
  "title_en": "The same in English",
  "summary_zh": "两三句：改了什么、怎么验证的",
  "summary_en": "The same in English",
  "not_done": "方案里没做成的部分，没有就留空"
}
```

只有代码没改完的时候 `done` 才给 false，并在 `not_done` 里说明卡在哪。没法亲自验证不算。
