# mindloop

两个人互相猜对方心思的模拟器：A 说话，B 猜 A 的意思；A 知道 B 会猜，B 知道 A 知道……
每多想一层，结论可能翻转一次。mindloop 把这种递归算出来、画出来，并配上来自小说、史书、喜剧和博弈论经典的真实案例。

## 运行

```bash
uv sync
uv run mindloop serve          # 打开 http://127.0.0.1:8765
```

内心独白由本机的 `claude -p` 生成，不需要 API key；没有 `claude` 时界面照常工作，只显示推理结论。

## 命令行

| 命令 | 作用 |
|---|---|
| `mindloop list` | 案例库（▶ 可运行，· 只有文字讲解） |
| `mindloop run kongchengji -a 3 -b 2` | 打印两个人脑中的塔和结局 |
| `mindloop sweep kongchengji -d 12` | 层数一路加深：收敛还是震荡，无限层的极限 |
| `mindloop narrate kongchengji` | 同 `run`，每层配一段 claude 写的内心独白 |
| `mindloop export <案例> -o out.jsonl` | 导出带独白的完整记录 |
| `mindloop bench generate` / `bench run bench.jsonl` | 由引擎出题、给标准答案，测模型的递归心智能力 |

## 原理

每个案例是一个小博弈（`cases/<类别>/<id>.yaml`）：

- **信号博弈**：a 知道隐藏的实情，说一句话；b 听到后形成判断并行动。
- **同时博弈**：两人各选一个行动，互相看不到。

第 0 层不动脑筋（照字面 / 凭直觉）；第 d 层针对「对方的第 d-1 层」做最优回应。
想到第 d 层的人脑中是一座塔：自己(d) ⊃ 对方(d-1) ⊃ 自己(d-2) ⊃ … ⊃ 第 0 层。
数值由 `recursion.py` 精确算出；文字独白由 `narrative.py` 让 claude 按每层的结论来写。

## 案例

五类：言外之意、虚张声势、默契协调、话里有私心、无限层与共同知识。
每个案例带出处；`source.verified: true` 表示回目和引文已对照原文核对过。

## 在统一入口里

world-sim 的 `idea-loom` 一个进程托管所有模拟，mindloop 在 `http://mindloop.localhost:8767/`。

- `sim.json` 是它的名片：每个案例一张卡，地址是 `/#c=<案例>&a=<层数>&b=<层数>`（读本只有 `c`）。加了或删了案例，要同时改 `sim.json`。
- 地址带 `?embed=1` 时只留舞台：没有案例库，简介收起；进来自动从第 0 层一层层播到原作的层数。
- 嵌入时不会一进来就调用模型，等有人点了才生成独白（一页上可能同时排着很多张卡）。
- 页面看不见时，播放和轮询都停下。

## 环境变量

`MINDLOOP_MODEL`（默认 sonnet）、`MINDLOOP_CLAUDE_BIN`、`MINDLOOP_CACHE`、`MINDLOOP_TIMEOUT`、`MINDLOOP_CASES`。

模型输出的缓存写在 `MINDLOOP_CACHE`；没设就写在 `$WORLD_SIM_STATE/llm`；再没有就是项目根的 `.cache/llm`。


# mindloop (English)

A simulator of two people guessing each other's minds: A speaks and B guesses what A means; A knows B will guess, and B knows A knows.
Each extra level of thought can flip the conclusion. mindloop computes this recursion, draws it, and pairs it with real cases from novels, histories, comedy and the game-theory classics.

## Run

```bash
uv sync
uv run mindloop serve          # open http://127.0.0.1:8765
```

Inner monologues are generated by the local `claude -p`; no API key is needed. Without `claude` the interface still works and shows only each level's conclusion.

## Command line

| Command | What it does |
|---|---|
| `mindloop list` | The case library (▶ runnable, · prose only) |
| `mindloop run kongchengji -a 3 -b 2` | Print both people's towers and the outcome |
| `mindloop sweep kongchengji -d 12` | Deepen level by level: converge or oscillate, and the infinite-depth limit |
| `mindloop narrate kongchengji` | Like `run`, with a monologue written by claude for each level |
| `mindloop export <case> -o out.jsonl` | Export a full record with monologues |
| `mindloop bench generate` / `bench run bench.jsonl` | The engine writes questions with gold answers to test a model's recursive mind-reading |

## How it works

Each case is a small game (`cases/<category>/<id>.yaml`):

- **Signaling game**: a knows a hidden state and says something; b hears it, forms a belief and acts.
- **Simultaneous game**: each picks an action without seeing the other's.

Level 0 does not think (literal reading, or gut feeling); level d best-responds to the other person's level d-1.
Someone thinking at level d holds a tower: self(d) ⊃ other(d-1) ⊃ self(d-2) ⊃ … ⊃ level 0.
The numbers are computed exactly by `recursion.py`; `narrative.py` has claude write each level's monologue to match that level's conclusion.

## Cases

Five groups: implicature, bluffing, tacit coordination, talk with a motive, and infinite levels / common knowledge.
Every case cites its source; `source.verified: true` means the chapter and quotation were checked against the original text.

## Inside the single entry point

world-sim's `idea-loom` hosts every simulation in one process; mindloop is at `http://mindloop.localhost:8767/`.

- `sim.json` is its card file: one card per case, at `/#c=<case>&a=<depth>&b=<depth>` (readers take only `c`). Adding or removing a case means updating `sim.json` too.
- With `?embed=1` only the stage remains: no library, summary folded away; on arrival it plays by itself from level 0 up to the source depths.
- When embedded it does not call the model on arrival; monologues are generated once someone interacts (a page may show many cards at once).
- While the page is hidden, playback and polling stop.

## Environment variables

`MINDLOOP_MODEL` (default sonnet), `MINDLOOP_CLAUDE_BIN`, `MINDLOOP_CACHE`, `MINDLOOP_TIMEOUT`, `MINDLOOP_CASES`.

The model-output cache goes to `MINDLOOP_CACHE`; if unset, to `$WORLD_SIM_STATE/llm`; failing that, to `.cache/llm` under the project root.
